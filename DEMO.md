# GridLock demonstration

Aim for 2–3 minutes. Run the static server and open the app once before presenting so the public basemap can load. Open the evidence register and a printable brief beforehand as backups; coordinate and matching data are local, while map tiles and external evidence need internet. Keep a downloaded text brief as an offline fallback.

1. **Problem (20 seconds):** Utilities publish plans separately. A planner needs to identify nearby projects that merit a coordination conversation. The map has 12 source projects, nine candidate pairs and two utilities. Three projects have no candidates. These are approximate locations, not route alignments.
2. **Discover (30 seconds):** Set the existing date-gap filter to “Within 1 year.” Five pairs remain. Select Jasper–Okatie × Goshen–McIntosh. Both markers highlight and the map fits the pair. Explain the 7.55-mile approximate center distance and 182-day target-date gap. Date proximity is not proof of simultaneous construction.
3. **Check evidence (30 seconds):** Expand the DESC source details. The sponsor workbook had a December 2025 target; the newer public 2026–2030 filing has December 1, 2026. The old value is preserved. Show the public PDF at page 12. Explain location confidence separately: workbook coordinates are not independently verified, and McIntosh has inconsistent positions in two workbook rows.
4. **Act (30 seconds):** Shortlist the pair. Toggle shortlist-only to show the saved selection. Open the impact model: use 1% assumed shareable budget and 10–30% assumed avoidance, then enter $2,000 coordination cost. The resulting approximately $17,280–$55,841 range is a hypothetical DESC-side sensitivity calculation using a published $19,280,474 project estimate, not a measured saving or a contractor quote. GPC costs are excluded.
5. **Take away (20 seconds):** Open printable brief. It carries the two projects, revised date, distance, uncertainty, source references, user assumptions and questions for the other team. Print/Save PDF uses the browser; Download brief creates portable text with source URLs.
6. **Optional rejection example:** Return to the map, clear selection, reset filters and reset the view. Select the Queensboro project near Charleston. It has no qualifying cross-utility pair. Projects are allowed to have zero or multiple candidates.

## What to say accurately

- This is a planning research aid. No coordination feasibility, current completion status, exact work route, or actual savings has been verified.
- The corrected guide uses center distance under 25 miles, with in-service gap as a secondary signal. Default order is closest first; date-gap sort is an optional exploration view.
- Basic deliverables are implemented. Source confidence is explicit; further geocoding remains a research task.
- Shortlists persist in this browser. Scenario edits last within the current workspace session and are embedded in the opened brief URL.
